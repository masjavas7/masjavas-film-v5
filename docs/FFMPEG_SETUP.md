# FFmpeg untuk build desktop

File `ffmpeg.exe` dan `ffprobe.exe` **tidak** disertakan di repository GitHub (ukuran > 100 MB).

Sebelum `npm run desktop:build`, letakkan binary Windows di:

```
resources/ffmpeg/win32/ffmpeg.exe
resources/ffmpeg/win32/ffprobe.exe
```

## Unduh

1. https://www.gyan.dev/ffmpeg/builds/ — pilih **release essentials**
2. Ekstrak `bin/ffmpeg.exe` dan `bin/ffprobe.exe` ke folder di atas
